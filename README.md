# Bolsa térmica (Em desenvolvimento!)
## Descrição geral
Este é um projeto de design e manufatura pessoal de uma bolsa térmica modular, flexível e eficiente, com suporte amplo para uso diário ou extenso. Ele inclui em suas branches secundárias possíveis módulos complementares que poderiam aumentar sua funcionalidade de alguma forma.
Esse arquivo seguirá a partir desse ponto a arquitetura de categorias disposta abaixo:

- Objetivos principais
- Projeto
  - Formato e dimensões
  - Fechamento
  - Alça e transporte
  - Rigidez
  - Camadas
    - Protetiva (interna)
    - Insulante térmico
    - Rígida
    - Emissiva
    - Protetiva (externa)
  - Técnicas oportunas
- Planejamento da montagem
  - Materiais finais
  - Etapas da montagem


## Objetivos principais
- Conservação de temperatura por períodos prolongados de tempo
- Portabilidade
- Resistência física a uso diário
- Capacidade de suporte a amplo intervalo de temperatura
- Usabilidade simples e conveniente antes, durante e após uso
